# 04 · 测试、准入与风险（V2）

## 0. 短信与来电优先验证

| 能力 | 受控测试 | 关键限制 |
| --- | --- | --- |
| 短信过滤 | 未知号码发送 SMS/MMS，验证分类映射与系统展示 | 不覆盖 iMessage 或通讯录联系人；扩展不能直接联网 |
| 来电识别/阻止 | 号码目录识别、阻止、关闭、reload、重复号码和非法号码 | 系统批量加载目录，不是每通电话实时查询 |
| 广告拦截 | 本阶段不执行真实 URL Filter 测试 | 仅保留研究记录，不纳入 V2 验收 |

## 1. 产品准入

先在受控资源上证明过滤正确，再在维护者指定的目标 App 上验证。任何成功率都必须带版本、设备、时间、网络条件和分母。

未确定目标 App 清单前，不承诺覆盖某品牌或“主流 App”。用户要求的开屏广告场景需要观察真实进入首页耗时，而不是只记录网络请求被阻止。

## 2. 核心验证矩阵

| 维度 | 最少包含 |
| --- | --- |
| 设备 | 普通非受监管真机；不能只有模拟器/受监管设备 |
| 签名 | 开发路径、拟采用的分发路径 |
| 状态 | 初次安装、拒绝授权、系统中启用/关闭、卸载/重装 |
| 网络 | Wi-Fi、蜂窝、IPv6-only、切换网络、断网、门户网络 |
| 请求 | URLSession、WebKit、未参与的自定义网络栈 |
| URL | 同域不同路径、查询参数、片段、编码、大小写、IDN |
| 缓存 | 系统裁决缓存、规则缓存、App 广告素材缓存 |
| 故障 | PIR 超时/不可达、损坏 Bloom、过期 manifest、签名失败 |
| 更新 | 旧客户端/新数据库、新客户端/旧数据库、回滚 |
| 共存 | 已有 VPN、加密 DNS、Private Relay 开/关 |
| 体验 | 大字体、VoiceOver、Reduce Motion、深色、小屏 |

涉及删除 App 数据、重装或更改系统网络配置时，使用专用测试设备并得到维护者授权。

## 3. 广告效果实验

固定 App 版本、设备、地区、网络和测试条件，交替运行关闭过滤/开启过滤组。记录：
- 是否出现开屏素材。
- 可进入首页的实际等待。
- 是否出现空白/错误页/重试。
- 登录、首页刷新、搜索、播放、购物/支付前流程等关键功能是否异常。
- 缓存和广告未投放等混杂因素。

不为测试实际购买商品或执行金融交易。支付类只验证授权测试环境或流程入口。

样本量、场景及通过阈值由维护者在测试前定稿；不能挑选成功截图代替实验。

## 4. 诊断证据

允许资源失败 → 联网或服务问题，不断言拦截成功。  
阻止资源失败 + 允许资源成功 → 仍检查是否符合预期错误与基线。  
仅获取 URL 裁决 → 说明“裁决测试”，不等于证明任意第三方 App 流量已拦截。  
没有足够证据 → “无法判断”。

可额外建立受控测试 App，显式展示广告请求失败时的不同退化行为，验证“阻断请求不等于跳过倒计时”。

## 5. 性能与成本

实测而非承诺：
- 开启前后正常资源延迟分布。
- 首次候选查询与缓存查询的区别。
- PIR 请求/响应体积、CPU 时间、峰值并发、内存。
- 数据集规模、Bloom 假阳性率与更新体积。
- 长时间使用后的系统能耗报告。
- 后端故障恢复与关闭配置的响应。

所有目标阈值在 G0 基线测量后定稿。未测之前不标“零耗电”“毫秒拦截”“万人零成本”。

## 6. 规则模块测试

当前包应测试：
- 大小写与尾随单点归一化。
- 非法域名/URL/通配符/端口/IP 拒绝。
- 后缀匹配点边界。
- 去重和稳定输出。
- 例外覆盖同域、父域、子域时的安全抑制。
- 允许项不与阻止项重叠时不影响。
- 空集行为。
- 非 ASCII 输入明确拒绝，不假装已支持 IDN。

待增加：
- 可信 IDNA 实现。
- Apple sub-URL 解析一致性。
- Bloom/PIR 联合样本。
- 签名、防重放、安全回滚。
- 大文件、畸形输入与内存上限。

## 7. 风险登记

| 风险 | 级别 | 处理 |
| --- | --- | --- |
| URL Filter 未覆盖目标广告网络实现 | 阻塞核心价值 | G0+真实 App 验证，不夸大范围 |
| PIR 成本超预算 | 阻塞商业化 | 实测，缩小规则/规模或重新评估产品 |
| 规则误拦登录/业务域名 | 高 | 保守规则、例外优先、全局关闭、回滚 |
| Bloom 与 PIR 版本不一致 | 高 | 联合快照、多版本迁移测试 |
| 授权/分发限制未满足 | 阻塞发布 | 普通设备与分发路径核验 |
| 隐私文案与真实网络行为不一致 | 高 | 数据流审查、日志最小化 |
| 第三方规则授权不清楚 | 高 | 未审计来源不进入发布 |
| Mock 进入 Release | 高 | 构建时隔离、启动自检 |
| UI 把配置启用当作拦截成功 | 中高 | 状态拆分、受控测试、准确文案 |
| 规则更新不及时 | 中高 | 前台检查+系统回调，过期提示 |
| 既有 VPN/DNS 共存问题 | 中高 | 组合实测，不先承诺 |
| 自动恢复时间无法保证 | 中 | V1 不提供定时恢复 |

## 8. 当前交付的验证边界

本包不会执行实际过滤。最终交付说明应附上实际运行的 Core 单元测试与 HTML 交互检查结果。
SwiftUI 源码在 Linux 环境中无法完成 Apple SDK 类型检查或 iPhone 真机验证；只能做可用的静态/语法检查，Mac Xcode 编译必须由后续开发补齐。
